# 生活小秘 - 微信小程序版

个性化智能吃喝玩乐服务平台，基于原 Web 原型改造为微信小程序。

## 项目结构

```
miniprogram/
├── app.js                    # 小程序入口，全局数据
├── app.json                  # 全局配置（页面路由、自定义TabBar）
├── app.wxss                  # 全局样式
├── project.config.json       # 项目配置
├── sitemap.json              # 搜索索引配置
│
├── custom-tab-bar/           # 自定义底部导航栏组件
│   ├── index.js
│   ├── index.json
│   ├── index.wxml
│   └── index.wxss
│
├── utils/                    # 工具模块
│   ├── data.js               # 模拟数据（分类/商家/推荐/上新/聊天等）
│   └── api.js                # API 客户端（后端可用时调用，否则用本地数据）
│
└── pages/                    # 页面
    ├── home/                 # 首页（平台精选中心）
    ├── recommend/            # 推荐页（个性化智能推荐）
    ├── assistant/            # 小秘智能体（AI对话助手）
    ├── newest/               # 上新页（新品动态社交种草）
    └── profile/              # 个人中心（用户资产管理）
```

## 功能模块

| 页面 | 功能 |
|------|------|
| 首页 | 智能搜索栏、8大分类入口、轮播图、附近热门商家、特价美食、限时秒杀 |
| 推荐 | 兴趣偏好自定义编辑、千人千面内容推荐、瀑布流展示 |
| 小秘 | 8大快捷指令、AI智能对话、卡片式回复、打字动画 |
| 上新 | 筛选标签、新品动态流、点赞/评论/分享社交互动 |
| 我的 | 用户信息卡片、资产展示、订单管理、常用功能、系统设置 |

## 如何使用

### 1. 导入项目
1. 打开 **微信开发者工具**
2. 选择「导入项目」
3. 项目目录选择 `miniprogram` 文件夹
4. AppID 填写你的小程序 AppID（或使用测试号）
5. 点击导入

### 2. 预览运行
- 导入后即可在开发者工具中预览
- 点击「预览」可生成二维码，用手机微信扫码体验
- 点击「真机调试」可在手机上实时调试

### 3. 后端对接（可选）
- 在 `app.js` 中设置 `apiBaseUrl` 为后端地址
- 小程序会自动检测后端可用性，可用时从 API 加载数据
- 后端不可用时自动回退到本地模拟数据
- 需要在小程序管理后台配置服务器域名白名单

## 技术特点

- **自定义 TabBar**：小秘中心按钮突出显示，渐变背景 + 阴影效果
- **纯前端可运行**：内置完整模拟数据，无需后端即可预览全部功能
- **响应式布局**：使用 rpx 单位，适配所有机型
- **自定义导航栏**：全页面 custom navigationStyle，沉浸式体验
- **组件化数据**：全局兴趣偏好共享，页面间数据同步
- **API 降级策略**：后端可用时走 API，不可用时自动降级到本地数据

## 与 Web 原型的差异

| 方面 | Web 原型 | 小程序版 |
|------|----------|----------|
| 框架 | 原生 HTML/CSS/JS | 微信小程序 WXML/WXSS/JS |
| 图标 | SVG 矢量图标 | Emoji 表情符号 |
| 图片 | picsum.photos 网络图 | CSS 渐变 + Emoji 占位 |
| 导航 | JS 手动切换 | wx.switchTab 原生切换 |
| 数据渲染 | DOM innerHTML | 数据绑定 + wx:for |
| 弹窗 | 自定义 modal | wx.showToast + 自定义面板 |
| 轮播 | JS 定时器 + transform | swiper 组件 |

## 后续开发建议

1. **接入真实后端 API**：替换 `utils/data.js` 为真实接口调用
2. **接入微信登录**：使用 `wx.login` + `wx.getUserProfile` 获取用户信息
3. **接入微信支付**：使用 `wx.requestPayment` 实现真实交易
4. **接入地图定位**：使用 `wx.getLocation` 获取用户位置，实现就近推荐
5. **接入大模型 AI**：将 `小秘` 对话接入真实 LLM API
6. **图片资源**：替换 Emoji 为真实图标字体或图片资源
7. **性能优化**：添加骨架屏、图片懒加载、分页加载
