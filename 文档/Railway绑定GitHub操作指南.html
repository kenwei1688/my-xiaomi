Railway 绑定 GitHub · 操作步骤页面

目的：把你的 GitHub 账号绑到 Railway 账号，之后往 GitHub 推代码就会自动部署上线。下面每一步都配有仿真界面，照着点即可。预计 2 分钟。

① 点头像 ② 账户设置 ③ Connect GitHub ④ GitHub 授权 ⑤ 开启自动部署 卡住怎么办

1 登录 Railway，点右上角头像

↑ 这是 Railway 后台的顶部栏，红圈处就是你的头像

你要做的：打开 railway.com 登录，点右上角那个圆形头像，会弹出一个菜单。
提示：如果已经登录，直接做这步就行。

2 选 Account Settings（账户设置）

↑ 头像菜单里点 "Account Settings"，左边栏找 GitHub / Connected Accounts

Connected Accounts

你要做的：在弹出的菜单里点 Account Settings，进入后在左侧找 GitHub 或 Connected Accounts，右边会看到一个 GitHub 行和 Connect 按钮。

3 点 Connect GitHub

↑ 点这个 Connect（连接）按钮，浏览器会自动跳到 GitHub
→ 点击后跳转到 github.com 授权页
你要做的：点 Connect GitHub。点了之后浏览器会自动打开 GitHub 的页面让你确认——这是正常的，不是在乱跳。
如果没跳，检查浏览器是不是拦截了弹出窗口，允许一下再点一次。

4 GitHub 页面：选仓库，点 Install

↑ GitHub 授权页，选能访问的仓库，勾选你的项目，点绿色 Install

Railway 想要访问你的账户

● All repositories（全部仓库，最省事）
○ Only select repositories（仅指定仓库）
✓ kenwei1688/my-xiaomi
建议直接选 "All repositories"，或至少勾选 kenwei1688/my-xiaomi。
你要做的：在 GitHub 页面，仓库权限那里勾选 kenwei1688/my-xiaomi（或选 All repositories 省事），然后点绿色 Install / Authorize 按钮。
装完会自动跳回 Railway，说明绑定成功。

5 回 Railway，开启自动部署

↑ 项目 → 服务 → Settings → Source，点 Enable 开启自动部署

你要做的：回到项目 2026-08-09-12-47-29 → 点服务 → Settings → Source。如果那里显示仓库已连接且有 Enable（启用） 按钮，点一下，自动部署就开了。
开启后，以后你（或我）往 GitHub 推代码，Railway 就会自动部署，不用再手动操作。
卡住怎么办？
1. 做完第 5 步 Source 仍显示未连接：打开 github.com/settings/installations，确认里面那个 Railway 应用能访问 kenwei1688/my-xiaomi 这个仓库。
2. 嫌麻烦不想装：Railway 服务页也有个手动 Deploy 按钮，每次手动从 GitHub 拉最新代码部署也能上线，只是不自动。
3. 弄完告诉我，我推一个测试提交帮你验证"push 即部署"是否跑通。
