## 三、后端服务部署（生产环境）

后端是 Node.js 零依赖服务，本地已验证运行于 `localhost:3000`。**单进程同源**：同一进程既提供 `/api/*` 接口，又托管 `../app` 静态前端（访问 `http://localhost:3000` 即前端，免 CORS）。健康检查 `/api/health` 返回全部 API 端点（含账号 / 云端提醒 / 行程 / AI 对话）。

### 方案一：Docker 一键部署（推荐）

```bash
# 前提：一台云服务器（腾讯云/阿里云轻量 2核2G，约 ¥50-100/月，Ubuntu 20.04+）
# 1. 上传项目（app/ + server/ + deploy/）到服务器 /opt/lexiang-life
# 2. SSH 登录后执行：
cd /opt/lexiang-life
sudo bash deploy/deploy.sh
# 3. 完成，访问 http://服务器IP:3000
```

### 方案二：systemd（免 Docker）

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt-get install -y nodejs
cp deploy/lexiang.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now lexiang
curl http://127.0.0.1:3000/api/health   # 验证
```

部署脚本支持可选 HTTPS（Let's Encrypt 免费证书），详见 `deploy/README.md`。

## 四、上线前必须补齐的差距（诚实清单）

当前版本是**功能完整的产品级 Demo**（前端 + 后端 + AI 引擎 + 多端覆盖），但真实面向公众运营仍需以下工作：

| 项目 | 现状 | 需要做的 |
|------|------|----------|
| 用户系统 | 模拟单用户 | 手机号验证码登录 + 真实用户表（MySQL/Redis） |
| 数据库 | JSON 文件持久化（单文件，轻量，重启不丢） | 高并发/大数据量时迁移 MySQL，接 `lexiang-data` 持久化卷 |
| 支付 | 无 | 微信支付/支付宝：需营业执照 + 商户号申请 |
| AI 对话 | 规则引擎（8 种意图识别） | 接入真实大模型 API（腾讯混元/DeepSeek/通义） |
| 商家后台 | 无 | 商家入驻、商品管理、订单处理后台 |
| 内容审核 | 无 | 上新页社区内容接入审核（微信内容安全 API） |
| 域名与备案 | 公网 IP 直连 | 中国大陆服务器必须 ICP 备案（约 1-2 周） |
| 上架 | 未上架 | 应用市场（应用宝/华为/小米）+ 隐私政策 + 用户协议 |
| 监控告警 | 无 | 云监控 + 日志采集 + 备份策略 |
